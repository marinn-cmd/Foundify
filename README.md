# Foundify - Versión React (Vite)

Proyecto migrado a React con la integración completa del componente interactivo `<PatternWaves />` de [React Bits](https://reactbits.dev).

## Ubicación exacta del proyecto
```

```

## Características
- **Vite + React 18**: Configuración moderna, ultra rápida y modular.
- **React Router DOM**: Navegación SPA entre rutas (`/`, `/register`, `/restablecer`, `/acerca-de`, `/contactanos`).
- **PatternWaves (React Bits)**: Renderizado WebGL nativo con `ogl`, interactividad al puntero/mouse, preset `silk`, color `#4a993c` y fondo `#000000`.
- **Diseño Responsivo y Limpio**: Formularios interactivos, validaciones y diseño coherente con la identidad de Foundify.

## Cómo ejecutar el proyecto en desarrollo
Abre una terminal en la carpeta del proyecto y ejecuta:
```bash
npm run dev
```
La aplicación se abrirá en `http://localhost:3000`.

## Cómo compilar para producción
```bash
npm run build
```
Los archivos optimizados y listos para producción se generan en la carpeta `dist/`.
